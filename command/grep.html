grep

使用正则表达式搜索文本（global regular expression print）

基本语法

grep [选项] 模式 [文件...]

常用选项

选项说明
-i忽略大小写
-v反向匹配，显示不包含模式的行
-r 或 -R递归搜索目录中的文件
-n显示匹配行的行号
-l只列出包含匹配内容的文件名
-c统计每个文件中的匹配行数
-E使用扩展正则表达式

常见用法

grep "error" log.txt

在 log.txt 中搜索包含 error 的行。

grep -i "error" log.txt

忽略大小写搜索 error、ERROR、Error 等。

grep -rn "TODO" src/

递归搜索 src 目录中所有文件，并显示行号。

grep -v "DEBUG" app.log

显示不包含 DEBUG 的所有日志行。

grep -E "^(error|warn)" log.txt

使用扩展正则匹配以 error 或 warn 开头的行。

Linux / macOS 差异

  • Linux（GNU）：grep -P 支持 PCRE 正则表达式，grep -r 递归搜索。
  • macOS（BSD）：没有 -P 选项；需要 Perl 兼容正则可安装 ggrep，或使用 -E 扩展正则。

注意事项

  • 模式包含特殊字符时建议加引号，避免 shell 解释。
  • grep -R 会进入符号链接，grep -r 默认不会。
  • 处理二进制文件时，可用 -I 忽略二进制文件，避免终端乱码。
