df

显示文件系统磁盘空间使用情况（disk free）

基本语法

df [选项] [文件或目录]

常用选项

选项说明
-h以人类可读方式显示大小
-T显示文件系统类型
-i显示 inode 使用情况
-t只显示总计

常见用法

df -h

以人类可读方式显示所有挂载点的磁盘空间。

df -hT

同时显示文件系统类型和可用空间。

df -h /

只查看根分区的使用情况。

df -i /home

查看 /home 分区的 inode 使用率。

注意事项

  • df 关注的是整个文件系统/分区的空间，而不是单个目录的大小。
  • 当 inode 使用率 100% 时，即使磁盘空间充足也无法创建新文件。
