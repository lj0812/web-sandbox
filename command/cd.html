cd

切换当前工作目录（change directory）

基本语法

cd [目录路径]

常用路径写法

路径说明
~当前用户的家目录
-返回上一次所在的目录
..上一级目录
.当前目录
/根目录

常见用法

cd /var/log

切换到 /var/log 目录。

cd ~

切换到当前用户的家目录。

cd ..

返回上一级目录。

cd -

在两个目录之间快速来回切换。

cd ../..

向上返回两级目录。

注意事项

  • 目录路径中包含空格时，需要用引号包裹或使用反斜杠转义：cd "My Documents"。
  • cd - 是一个非常实用的小技巧，适合在调试时快速回到上一个目录。
