cat

连接文件并输出到标准输出（concatenate）

基本语法

cat [选项] [文件...]

常用选项

选项说明
-n显示行号
-b对非空行显示行号
-s压缩多个连续空行成一个空行
-E在每行末尾显示 $ 符号

常见用法

cat file.txt

查看 file.txt 的完整内容。

cat -n file.txt

查看内容并显示行号。

cat file1.txt file2.txt > combined.txt

将多个文件内容合并到一个新文件。

cat > new.txt

从标准输入创建文件，输入完成后按 Ctrl+D 结束。

cat file.txt | grep keyword

将 cat 的输出通过管道传给 grep 进行过滤。

注意事项

  • 大文件不建议直接用 cat 查看，推荐使用 less 或 more。
  • 使用重定向 > 时要小心，会覆盖目标文件原有内容。
