git

分布式版本控制系统

基本语法

git [子命令] [选项]

常用子命令

子命令说明
clone克隆远程仓库到本地
status查看工作区状态
add将文件变更加入暂存区
commit提交暂存区的变更
push将本地提交推送到远程仓库
pull从远程仓库拉取并合并变更
log查看提交历史
branch管理分支

常见用法

git clone https://github.com/user/repo.git

克隆远程仓库。

git status

查看当前工作区的修改与暂存状态。

git add file.txt

将 file.txt 的变更加入暂存区。

git commit -m "修复登录 bug"

提交暂存区的变更并附上说明。

git push origin main

将本地 main 分支推送到远程 origin。

git log --oneline -10

以一行的格式查看最近 10 条提交。

git checkout -b feature/login

创建并切换到新分支 feature/login。

注意事项

  • 提交前先用 git status 和 git diff 确认变更内容。
  • git pull 等价于 fetch + merge，冲突时需要手动解决。
  • 不要提交敏感信息（密码、密钥），可使用 .gitignore 忽略。
