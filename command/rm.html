rm

删除文件或目录（remove）

基本语法

rm [选项] 文件或目录...

常用选项

选项说明
-r 或 -R递归删除目录及其内容
-f强制删除，不提示确认，忽略不存在的文件
-i删除前逐一询问确认
-v显示删除过程

常见用法

rm file.txt

删除单个文件。

rm -r old_project

递归删除目录 old_project 及其所有内容。

rm -rf temp/

强制递归删除 temp 目录，无确认提示。

rm -i *.log

删除所有 .log 文件前逐个询问。

注意事项

  • rm -rf / 会尝试删除整个文件系统，绝对不要执行。
  • 删除后的文件通常无法恢复，删除前建议先用 ls 确认目标。
  • 对通配符要特别小心，如 rm * 会删除当前目录下所有文件。
