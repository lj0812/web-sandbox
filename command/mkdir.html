mkdir

创建目录（make directories）

基本语法

mkdir [选项] 目录名...

常用选项

选项说明
-p递归创建父目录，若已存在则不报错
-v每创建一个目录就输出一条信息
-m创建时指定权限模式，如 -m 755

常见用法

mkdir project

在当前目录下创建 project 目录。

mkdir -p project/src/main/java

一次性创建多层嵌套目录。

mkdir -p logs/2024/01 logs/2024/02

同时创建多个目录结构。

mkdir -m 700 private

创建目录并直接设置权限为 700。

注意事项

  • -p 是 mkdir 最常用的选项，可避免因父目录不存在而失败。
  • 如果目录名包含空格，需要加引号：mkdir "my folder"。
