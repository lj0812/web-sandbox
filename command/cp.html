cp

复制文件或目录（copy）

基本语法

cp [选项] 源文件 目标文件
cp [选项] 源文件... 目标目录

常用选项

选项说明
-r 或 -R递归复制目录及其内容
-i覆盖前提示确认
-f强制覆盖，不提示
-p保留原文件的权限、时间戳等属性
-v显示复制过程

常见用法

cp file.txt backup.txt

将 file.txt 复制为 backup.txt。

cp -r project project_backup

递归复制整个 project 目录为 project_backup。

cp *.log /var/backup/

将所有 .log 文件复制到 /var/backup/ 目录。

cp -rp project/ /mnt/backup/

保留属性并递归复制目录。

注意事项

  • 复制目录必须加 -r，否则只会报错。
  • 目标为已存在目录时，cp 会把源文件放入该目录中；若目标不存在，则创建副本。
