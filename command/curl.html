curl

在命令行中传输数据，支持多种协议（client URL）

基本语法

curl [选项] [URL]

常用选项

选项说明
-X指定 HTTP 方法，如 GET、POST、PUT、DELETE
-H添加请求头
-d发送 POST 数据
-o将响应保存到指定文件
-O使用远程文件名保存
-L跟随重定向
-s静默模式，不显示进度信息
-I只获取响应头

常见用法

curl https://api.example.com/users

发送 GET 请求并输出响应体。

curl -O https://example.com/file.zip

下载文件，并保留远程服务器上的文件名。

curl -X POST -H "Content-Type: application/json" -d '{"name":"test"}' https://api.example.com/users

发送 JSON 格式的 POST 请求。

curl -L -o page.html https://example.com/page

跟随重定向并保存为 page.html。

curl -I https://example.com

只查看响应头信息。

注意事项

  • 默认情况下 curl 不跟随 3xx 重定向，需要加 -L。
  • 请求参数中包含 & 符号时，URL 应加引号，避免被 shell 解释。
  • 调试接口时可组合 -v 查看完整请求与响应过程。
