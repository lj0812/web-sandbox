Linux 与 macOS 命令差异

本手册中的命令大多同时适用于 Linux 与 macOS，但部分命令因 GNU（Linux 常见）与 BSD（macOS 常见）实现不同而有差异。

下表列出本手册中出现、且在两个平台上行为或选项不同的命令。如果某命令未在此列出，通常可认为在 Linux 与 macOS 上的常见用法一致。

命令差异速查

命令Linux（GNU）macOS（BSD）
du du -h --max-depth=1 限制递归深度 du -h -d 1 限制递归深度；GNU 长选项不支持
ls ls --color=auto 启用颜色输出 ls -G 启用颜色输出；也可通过 CLICOLOR=1 环境变量开启
top 交互键：M 按内存排序，P 按 CPU 排序，k 终止进程 交互键不同：o 选择排序字段，q 退出；启动参数差异较大
ps 支持大量 GNU 扩展选项，如 --sort=-%mem ps aux / ps -ef 可用，但高级选项较少，输出列略有不同
tar GNU tar 支持 --exclude=pattern 等长选项 BSD tar 常用短选项兼容；排除规则用 --exclude 也支持，但行为细节可能不同
grep grep -P 支持 PCRE 正则；grep -r 默认递归目录 无 -P 选项；可用 -E 扩展正则或安装 ggrep
find 支持 -printf、-delete、-maxdepth 等 GNU 扩展 -maxdepth 可用，但 -printf 和 -delete 不存在；删除需配合 -exec rm
cp / rm GNU 提供许多长选项，如 --preserve=mode,timestamps、--no-preserve=ownership 短选项 -p、-r、-f 等通用，长选项大多不支持

通用建议

  • macOS 上可通过 Homebrew 安装 GNU 版本（如 coreutils、grep、findutils），使用 gdu、ggrep、gfind 等命令获得与 Linux 一致的 GNU 行为。
  • 若脚本需要同时兼容 Linux 与 macOS，优先使用 POSIX 标准选项（短选项），避免 GNU 长选项。
  • 对 sed -i 这类常用但差异明显的命令，本手册未单独成页，兼容写法为 sed -i.bak 's/old/new/' file。
