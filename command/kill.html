kill

向进程发送信号，通常用于终止进程

基本语法

kill [信号] PID...

常用信号

信号说明
TERM 或 -15默认信号，请求进程正常退出
KILL 或 -9强制终止，进程无法捕获或忽略
HUP 或 -1挂起信号，常用于重新加载配置文件
INT 或 -2中断，等价于按 Ctrl+C

常见用法

kill 1234

向 PID 为 1234 的进程发送默认 TERM 信号。

kill -9 1234

强制终止 PID 为 1234 的进程。

kill -HUP nginx

向 nginx 进程发送 HUP 信号，通常用于重新加载配置。

killall firefox

按名称终止所有 firefox 进程（需要 killall 命令）。

注意事项

  • 优先使用默认 TERM（-15），给进程清理资源的机会；强制 -9 可能导致数据丢失。
  • 终止前先用 ps 或 top 确认目标 PID。
  • killall 和 pkill 可按名称终止进程，但要防止误杀同名进程。
