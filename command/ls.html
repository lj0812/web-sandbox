ls

列出目录内容（list directory contents）

基本语法

ls [选项] [文件或目录]

常用选项

选项说明
-l长格式列出详细信息（权限、所有者、大小、时间等）
-a显示所有文件，包括以 . 开头的隐藏文件
-h以人类可读方式显示文件大小（如 1K、23M）
-d只列出目录本身，而不是目录内容
-t按修改时间排序，最新的在前
-r反向排序
-S按文件大小排序，最大的在前
-R递归列出子目录内容

常见用法

ls -la

显示当前目录下所有文件（含隐藏文件）的详细信息。

ls -lh /var/log

以人类可读大小显示 /var/log 目录内容。

ls -lt

按修改时间倒序列出文件，最新修改的排在最前。

ls -ld */

只列出当前目录下的所有子目录本身。

Linux / macOS 差异

  • Linux（GNU）：ls --color=auto 启用颜色输出。
  • macOS（BSD）：使用 ls -G 启用颜色，或设置环境变量 CLICOLOR=1；不支持 --color 长选项。

注意事项

  • -lh 组合选项非常常用，推荐日常使用。
  • 以 - 开头的文件在命令行中容易被误认为是选项，可用 ls -- -filename 避免解析错误。
  • 不同发行版对 ls 的默认别名可能不同（如 CentOS 常默认带 --color）。
