find

在目录树中查找文件

基本语法

find [路径] [表达式]

常用条件与动作

选项说明
-name按文件名匹配，区分大小写
-iname按文件名匹配，忽略大小写
-type按类型查找：f 文件、d 目录、l 符号链接
-size按大小查找，如 +100M、-1G
-mtime按修改时间查找，如 -7 表示 7 天内
-exec对找到的文件执行命令
-maxdepth限制递归深度

常见用法

find . -name "*.txt"

在当前目录及子目录中查找所有 .txt 文件。

find /var/log -type f -mtime +7

查找 /var/log 下 7 天前修改过的普通文件。

find . -type f -size +100M

查找大于 100MB 的文件。

find . -name "*.log" -exec rm {} \;

找到所有 .log 文件并删除。注意 {} 与 \; 的用法。

find . -maxdepth 2 -type d

只查找当前目录下两层内的子目录。

Linux / macOS 差异

  • Linux（GNU）：支持 -printf、-delete 等扩展动作。
  • macOS（BSD）：-maxdepth 可用，但无 -printf 和 -delete；删除文件建议用 -exec rm。

注意事项

  • 通配符在 find 的 -name 中需要加引号，否则会被 shell 提前展开。
  • -exec 每次执行一个文件效率较低，可改用 -exec ... {} + 批量处理。
  • 在 / 下执行 find 通常需要 root 权限，并可能耗时较长。
