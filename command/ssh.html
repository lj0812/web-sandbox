ssh

安全远程登录到另一台主机（secure shell）

基本语法

ssh [选项] [用户@]主机 [命令]

常用选项

选项说明
-p指定远程端口，默认 22
-i指定私钥文件
-L本地端口转发
-R远程端口转发
-C启用压缩
-v显示详细调试信息

常见用法

ssh user@192.168.1.100

以 user 身份登录到远程主机。

ssh -p 2222 admin@example.com

使用非默认端口 2222 登录。

ssh -i ~/.ssh/id_rsa user@example.com

使用指定私钥文件进行密钥认证登录。

ssh user@example.com "ls -la"

登录后执行单条命令并返回结果。

ssh -L 8080:localhost:80 user@example.com

将本地 8080 端口转发到远程主机的 80 端口。

注意事项

  • 首次连接会提示确认主机指纹，确认后才会保存到 ~/.ssh/known_hosts。
  • 建议使用密钥认证替代密码登录，并禁用 root 密码登录以提高安全性。
  • 端口转发场景下，保持 ssh 会话连接，转发才会生效。
